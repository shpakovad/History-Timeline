# History Timeline

Интерактивная круговая таймлайн-анимация с использованием React, TypeScript, GSAP и кастомной геометрией расположения точек по окружности.  

## Функциональность

- Круговой таймлайн с плавной анимацией поворота (GSAP)
- Отображение периодов истории и связанных дат
- Переключение периодов через:
  - клики по точкам на окружности
  - навигацию кнопками
  - swiper-слайдер
- Поддержка мобильной и десктопной версии
- Клик-анимация

## Технологии

- **React 19**
- **TypeScript**
- **GSAP 3**
- **Webpack 5**
- **Swiper 12**
- **SASS / SCSS**

## Установка и запуск

### 1. Склонировать репозиторий:
git clone https://github.com/shpakovad/History-Timeline.git

### 2. Установить зависимости:
npm install

### 3. Запустить проект:
npm start

Приложение будет доступно по адресу: http://localhost:3000
